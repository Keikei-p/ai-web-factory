# AI Web Factory

Web制作案件を 受付 → 整理 → 仕様書 → 承認 → ローカル制作 → 品質確認 → 修正 → 納品準備 まで管理する、1人用のローカル制作システムです。

現在は Windows PC内だけで動く・外部AIなし・API料金なし の構成です。ログインやクラウド公開も行いません。

## 現在できること

- 案件の手動登録・編集・検索・ステータス絞り込み
- 入力項目から不足情報と顧客確認事項を整理
- 事実と推奨案を分離
- 制作仕様書の下書き生成・版管理
- 古い分析や仕様書の検出
- 制作仕様書の正式承認・差し戻し
- 未確定事項がある仕様書の承認拒否
- 承認済み仕様書から静的Webサイトをローカル生成
- 複数ページのPC内プレビュー
- メインカラー、見出し、説明文、CTA、ファーストビューの定型修正
- 修正ごとのサイト版管理
- 必須ページ、内部リンク、画像参照、SEO、レスポンシブ、アクセシビリティ基礎の自動品質チェック
- 制作開始・最終納品の明示承認
- 納品用フォルダのPC内書き出し
- 操作・承認・修正履歴
- SQLite保存、再起動後の保持、DB整合性チェック
- 1日1回の自動バックアップと手動バックアップ
- Windows 1クリック起動
- GitHub Actionsによるセキュリティ監査、型チェック、自動テスト、ビルド

## 基本フロー

案件登録 → ローカル分析 → 不足情報の補完 → 制作仕様書生成 → 仕様書承認 → 制作待ち → 制作開始承認 → 制作中 → ローカルサイト生成 → プレビュー → 品質チェック → 定型修正 → 再チェック → 最終確認 → 最終納品承認 → 納品用フォルダ書き出し → 納品

## 保存場所

- DB: data/ai-web-factory.db
- DBバックアップ: data/backups/
- 生成サイト: data/generated/
- 納品用コピー: data/exports/

これらはGitHubへ保存しません。

## ローカルURL

- Web画面: http://127.0.0.1:5173
- API: http://127.0.0.1:8787

外部公開はしません。

## Windowsで使う

初回はリポジトリを取得して npm install を実行します。開発用起動は npm run dev です。

install-desktop-shortcut.bat を一度実行すると、デスクトップに AI Web Factory と AI Web Factory 終了 のショートカットを作成できます。

## 自動確認

npm run verify で、TypeScript型チェック、API自動テスト、本番ビルドをまとめて確認できます。GitHub Actionsでは依存パッケージのセキュリティ監査も実行します。

## 現在の制限

外部AIを使わない方針のため、現在は自由文を生成AIで深く解釈したり、自由文だけで任意のコード修正をしたりはしません。代わりに安全な定型修正フォームを使います。

また、顧客への自動連絡、Gmail・LINE・Lancers・ココナラ連携、ドメイン購入、DNS変更、有料契約、課金、本番公開は行いません。

## 安全ルール

- 存在しない顧客情報を作らない
- 不明情報は不明のまま保持する
- 顧客情報を勝手に変更しない
- 制作開始を自動承認しない
- 最終納品を自動承認しない
- 顧客連絡・課金・契約・ドメイン・DNS・本番公開を自動実行しない
- ステータスを飛ばして進行させない
- 重要操作は履歴に残す

## 主なデータ

- projects: 案件
- project_analyses: 分析
- project_specs: 制作仕様書
- project_approvals: 承認
- project_history: 操作履歴
- site_builds: 生成サイト
- quality_checks: 品質チェック
- revision_requests: 修正履歴

外部AIを将来接続する場合も、現在のローカル安全設計を維持したまま追加できる構造にします。
